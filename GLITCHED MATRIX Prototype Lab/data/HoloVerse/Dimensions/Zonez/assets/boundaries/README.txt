Boundary asset slots

Default behavior
- Outer walls render as the current zone sky color.
- Sky blend textures come from *_ceiling.png when present.

Optional per-wall PNG overrides
- <zone_key>_north.png
- <zone_key>_south.png
- <zone_key>_east.png
- <zone_key>_west.png
- <zone_key>_north_east.png
- <zone_key>_north_west.png
- <zone_key>_south_east.png
- <zone_key>_south_west.png

You can place those files either directly in this folder or in assets/boundaries/walls/.
