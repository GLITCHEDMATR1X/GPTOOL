# HoloUtopia building inspection

Pass 19 adds the highlight/inspection contract used by future runtime selection.

Rules:

- Every town block and residential lot can be inspected.
- Authored data remains read-only.
- Interior blueprints load only when a compatible building is highlighted.
- Only one lazy interior should be loaded at a time.
- Selection panels can show purpose, residents, workers, capacity, active citizens, schedule nodes, and interior policy.
- Runtime state and activity history belong in saves/logs, not these authored files.

Generated index:

- `building_highlight_index.json` is a derived, committed proof index.
- It can be regenerated by `tools/validate_holoutopia_building_inspector.py` or by importing `holoutopia_building_inspector.write_highlight_index`.
