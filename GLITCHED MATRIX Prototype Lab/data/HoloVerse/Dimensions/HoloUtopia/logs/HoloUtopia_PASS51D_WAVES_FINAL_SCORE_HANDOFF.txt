HoloUtopia Pass 51D - Core Ring Waves and Final Score

Scope:
- Keep Adventure Simulation embedded in the Central Core Ring around the pyramid.
- Make combat feel more like a match with waves, class-specific action visuals, hit effects, and final scoring.

What changed:
1) Waves
- Added deterministic Core Ring enemy wave state.
- Wave interval: 70 seconds.
- Max waves: 4.
- Later waves add enemy pressure.

2) Class action visuals
- Mage: cyan arc bolt.
- Blade: gold slash.
- Archer: green rune arrow.
- Mender: violet ward.
- Actions now include visual IDs, colors, and class summaries.

3) Hit effects
- Added hit-effect metadata per active hero action.
- Runtime draws small collisionless hit sparks in the Core Ring.

4) Final score state
- Match still lasts 300 real seconds.
- End window exposes final score, survivor/queue bonuses, and grade.
- Watch Mode reports final score when the match reaches final state.

5) Screenshot determinism
- Screenshot renderer can freeze the runtime clock with _screenshot_clock_override so proof captures do not drift while Panda3D renders.
- This is inert in normal gameplay unless the screenshot tool sets the override.

Preserved:
- No HoloVerse routing changes.
- No HoloCore changes.
- No artifact routing changes.
- No collision changes.
- No player control yet.
- No external dimension route.
- Combat remains inside the Central Hub circle around the pyramid.
