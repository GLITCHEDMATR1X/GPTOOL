HoloUtopia Pass 34 - Stylized Structure Pass

Scope:
- Improve the look of authored city structures without changing data schemas.
- Make structure outlines read more clearly in motion and screenshots.
- Add more intentional facade detail so buildings do not feel like plain boxes.
- Keep this additive and safe for the standalone project.

Changed file:
- data/HoloUtopia/holoutopia_town_blocks.py

What changed:
1) Thicker structure lines
- Increased local 3D model-detail line thickness.
- Increased foundation outline thickness.
- Increased massing base/top outline thickness.
- Increased vertical edge thickness.
- Increased selected floor-band thickness.

2) Brighter solid structure faces
- Tweaked solid face color conversion so building volumes read better against the dark holo-grid.
- Kept default buildings opaque and selected buildings transparent for cutaway inspection.

3) Added stylized facade design helpers
- facade spines: vertical trim lines on front and side faces.
- facade frame: large front/side trim rectangles.
- roof crown: inset roof perimeter band above the roofline.
- entry portal: stronger front-door framing for residential kits.

4) Residential model detail pass
- Residential stacks/dorms/micro residences/courtyard homes now get:
  - thicker balcony rails
  - entry portal framing
  - terrace bands on taller residential forms
  - small roof peak accent on micro residences
  - existing roof courtyard ring preserved for courtyard_home
