HoloUtopia Pass 37 - Residential Population Rules

Scope:
- Start populating Residential Alpha using virtual garrison rules.
- Keep rendering safe by showing capped outdoor representatives, not 1000 actors.
- Preserve authored 44 citizens/schedules and add the 1000-resident model beside them.

Rules implemented:
- 24hr game clock.
- 1 earth minute = 1 game hour; full day = 1440 seconds.
- Default world population = 1000.
- All citizens live in Residential Alpha.
- Work and activity phases happen outside Residential.
- Max outdoor population per district = 20.
- Energy lasts 15 game hours outside; recharge requires 9 game hours inside a home garrison.
- Residential building garrisons are tiered 10 / 20 / 40 / 50, capped at 50 per garrison wing.
- Supplemental abstract garrison wings are allowed so Residential can house the 1000 default population before all physical residential expansion buildings exist.
