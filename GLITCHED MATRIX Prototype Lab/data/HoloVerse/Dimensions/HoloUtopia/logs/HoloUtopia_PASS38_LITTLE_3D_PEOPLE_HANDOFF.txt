HoloUtopia Pass 38 - Little 3D People Citizen Visuals

Scope:
- Keep Pass 37 Residential population/garrison rules intact.
- Replace oversized robot-style citizen markers with small humanoid 3D people.
- Remove circles/contact pads around citizens.
- Remove citizen name labels from the in-world street view.
- Keep the 1000-person virtual population model with max 20 outdoor representatives.

Changed files:
- data/HoloUtopia/holoutopia_game_runtime.py
- data/HoloUtopia/tools/render_holoutopia_in_world_runtime_screenshot.py
- data/HoloUtopia/tools/validate_holoutopia_robot_civilians.py
- data/database/utopia/runtime/holoutopia_runtime_bridge.json

What changed:
1) Citizen visual profile
- Runtime style changed to tiny_3d_people.
- Height reduced to 7.5 city units before world scale.
- Width/depth reduced so citizens read as little 3D figures.
- Body and limb line thickness reduced.
- No name labels.
- No contact pads.
- No ground rings.
- No collision geometry.

2) Runtime marker geometry
- Replaced large directional robot body with compact humanoid line body.
- Added small torso box, head box, arms, and legs.
- Kept facing direction and procedural limb swing.
- Kept click/inspector support through the citizen root tag.

3) Residential street placement
- Virtual Residential representatives now use explicit street positions.
- Departure/return citizens are placed on streets instead of inside/above buildings.
- Same-node spread remains deterministic, but no longer creates ring visuals.

4) Screenshot proof helper
- Added residential_people_close camera view for checking people at street scale.

Validation run:
- python -m compileall -q main.py data/HoloUtopia
- python data/HoloUtopia/tools/validate_holoutopia_robot_civilians.py
- python data/HoloUtopia/tools/validate_holoutopia_residential_population.py
- python data/HoloUtopia/tools/render_holoutopia_in_world_runtime_screenshot.py --view residential_people_close --clock 06:30
- python data/HoloUtopia/tools/render_holoutopia_in_world_runtime_screenshot.py --view residential_population --clock 06:30

Notes:
- This pass does not change population totals or garrison rules.
- This pass does not change HoloVerse/artifact routing.
- This pass intentionally keeps only 20 outdoor representatives visible for performance.
