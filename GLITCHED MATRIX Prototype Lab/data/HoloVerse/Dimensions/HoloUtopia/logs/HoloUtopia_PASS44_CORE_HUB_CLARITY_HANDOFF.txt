HoloUtopia Pass 44 - Core Hub Clarity

Scope:
- Make the central Simulation/Core read as the main raised city hub from atlas/world-view cameras.
- Prevent authored central buildings/neighborhood props from visually sitting on top of the Core.
- Keep this visual-only and preserve the citizen, schedule, population, commute, and pathfinding systems.

Changed files:
- data/HoloUtopia/holoutopia_city_world_style.py
- data/HoloUtopia/holoutopia_game_runtime.py
- data/HoloUtopia/holoutopia_town_blocks.py

- data/HoloUtopia/tools/validate_holoutopia_city_world_style.py
- data/database/utopia/runtime/holoutopia_runtime_bridge.json

What changed:
1) Raised central Simulation/Core hub
- Added a late overlay layer so the central hub renders after local district massing/activity props and before citizens.
- Lifted/widened the central hub visual with a larger dark clearance plate, layered plaza, rings, spokes, gateway pylons, pyramid core, and vertical beam.

2) Removed building-on-core read
- Central Core authored blocks now render only as low plaza pads.
- Central neighborhood overlay is suppressed in the world atlas; data remains intact for future interior/lore work.
- Simulation Hub activity props are lowered to compact glyphs so they no longer compete with the core silhouette.

3) Safety
- Collisionless visual-only pass.
- No route, schedule, garrison, population, or citizen behavior changes.
- No authored data mutation beyond runtime bridge flags.
