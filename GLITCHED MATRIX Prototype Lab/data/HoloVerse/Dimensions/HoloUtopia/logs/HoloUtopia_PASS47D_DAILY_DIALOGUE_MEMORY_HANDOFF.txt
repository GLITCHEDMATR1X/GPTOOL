HoloUtopia Pass 47D - Daily Dialogue Memory

Scope:
- Prevent citizens from repeating the same dialogue within the same in-game day.
- Keep dialogue proximity-only, brief, capped, and non-overlapping.
- Keep answers runtime-state based with safe unknown fallback.
- Keep memory runtime-only; no authored data writes.

Changed files:
- data/HoloUtopia/holoutopia_citizen_dialogue.py
- data/HoloUtopia/holoutopia_game_runtime.py
- data/HoloUtopia/tools/validate_holoutopia_daily_dialogue_memory.py
- data/database/utopia/dialogue/citizen_dialogue_rules.json
- data/database/utopia/runtime/holoutopia_runtime_bridge.json

Behavior:
- Accepted speeches record same-day keys by pair, question ID, speaker line, and answer text.
- Repeated pair/question/answer attempts are skipped and alternate approved questions are tried.
- Daily memory resets automatically when the in-game day changes.
- Speech bubbles remain small; max active bubbles remains 3.
- Garrisoned citizens remain silent.
- Citizens only talk near other visible citizens.
